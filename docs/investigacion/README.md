# Investigación · reunión del 21 de octubre de 2026

Cuatro documentos para decidir los temas que quedaron abiertos en la reunión con Oscar. Cada cifra lleva su fuente y la fecha de consulta (21-10-2026). Lo que no se pudo confirmar está en la sección "Qué falta confirmar" de cada documento. Las recomendaciones están marcadas como opinión nuestra, no como dato.

| # | Tema | Hallazgo principal |
|---|---|---|
| [01](01-boleta-electronica-sii.md) | Boleta electrónica SII | Toda venta en efectivo o transferencia exige boleta electrónica. Lo más rápido es emitirla por la API de un proveedor (Lioren: 0,1 UF/mes por el módulo de boleta y API sin costo). |
| [02](02-precios-y-competencia.md) | Precios y competencia | El único software chileno de farmacias con precio publicado (Control Farma) cobra 2–3 UF + IVA al mes más implementación. Lioren por módulos ronda 0,8 UF (~34 USD), en línea con los ~30 USD que se mencionaron en la reunión. |
| [03](03-pedidos-delivery.md) | Pedidos de delivery | Rappi, PedidosYa y Uber Eats tienen API, pero con aprobación comercial. Antes que eso, la farmacia necesita autorización del ISP para vender en línea, y las recetas-cheque quedan excluidas. |
| [04](04-costos-produccion.md) | Costos de producción | Salir a producción cuesta unos 46 USD al mes. No es opcional: los Términos de Vercel prohíben el plan Hobby para uso comercial. |
